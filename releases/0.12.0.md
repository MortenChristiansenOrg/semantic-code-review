# v0.12.0 — 2026-11-02

## Overview

Reviewing in the viewer is quicker and clearer. Stages show which steps belong to them, you can approve a whole folder at once, and **Since approval** no longer mixes target-branch changes into the stage's own changes.

Versions beginning with zero remain experimental: any release, including a patch, may contain breaking changes.

## Breaking changes

None.

## Improvements

- **Clearer stages.** Each stage is now a card that holds its header, its steps and its approval. An open stage lists its steps under **Steps in stage 01** and ends with an **Approve stage 01** button, so it is clear which stage an approval belongs to. On narrow screens the cards use the full width.
- **Shorter stage headers.** **Why this stage** now shows only its label. Hover over it or move to it with the keyboard to read the explanation.
- **Approve a folder at once.** Each folder in a step shows how many of its files you have approved. A button next to the count approves every file in the folder that still needs it, including files whose approval went stale.
- **Line comments in Since approval.** You can now add line comments while **Since approval** is on. They attach to the current file and line. Lines removed since your approval can still take a file comment.
- **Target-branch updates are kept apart from corrections.** When the agent moves the implementation onto a newer target branch, **Since approval** shows only the stage's own changes since you approved. **Include base changes** adds the target-branch changes back. If the two overlap and cannot be separated, the comparison says so. The viewer also shows a notice that the move happened, and the agent's feedback summary names the target branch.

## Bug fixes

- **Collapsed stages are skipped by the keyboard.** Before, pressing Tab could move into the hidden contents of a collapsed stage. Now it skips them.
- **Long tooltips stay on screen.** A tooltip taller than the window used to run off the bottom of the screen. Tooltips now fit the window, and you can scroll them with a mouse or touchpad.

## Updating

Run `/semantic-flow update`, or download `semantic-flow-0.12.0.zip` and its `.sha256` checksum, verify them, and install the complete extracted `semantic-flow` folder.

Node.js 20 or newer and Git remain required for the CLI and viewer. Windows, macOS, and Linux are supported. The implementation and feedback formats remain experimental `0.1` and did not change.

## Known issues

- **Very long tooltips can't be scrolled with the keyboard.** If a stage explanation is taller than the window, keyboard-only users see only the part that fits. Screen readers still read all of it. Tracked in [#143](https://github.com/MortenChristiansenOrg/semantic-code-review/issues/143).

# v0.6.0 — 2026-09-24

## Overview

Read Markdown documents as rendered previews and wrap long lines while reviewing files in the Viewer. Both controls preserve your source view and review context.

Versions beginning with zero remain experimental: any release may contain breaking changes.

## Breaking changes

None.

## Improvements

- Markdown files now offer **Source / Preview**. Preview renders the complete file at the recorded head revision, or the base revision for a deleted file, with headings, lists, tables, task lists, and fenced code. The displayed revision identifies which version you are reading.
- Relative links open repository files as plain text, and supported images load from the same revision. Embedded scripts, unsafe links, and interactive HTML are removed. Switch back to Source to inspect changes or leave line feedback; drafts and source settings are retained.
- **Wrap lines** makes long lines and unbroken strings readable in file and diff views. It starts off, remembers your choice across files and reloads, and preserves line numbers and feedback anchors.

## Updating

Run `/semantic-flow update`, or download `semantic-flow-0.6.0.zip` and its `.sha256` checksum, verify them, and install the complete extracted `semantic-flow` folder. Node.js 20 or newer and Git remain required for the CLI and Viewer; Windows, macOS, and Linux are supported.

The implementation and feedback formats remain experimental `0.1`. This release introduces no format migration. If upgrading from before v0.5.0, also read the intervening releases' breaking changes before continuing existing reviews.

## Known issues

- Markdown preview shows a complete file, not a rendered diff, and line feedback remains available in Source. Files above 4 MiB, binary link targets, and unsupported image formats cannot be previewed; repository images support PNG, JPEG, GIF, and WebP.

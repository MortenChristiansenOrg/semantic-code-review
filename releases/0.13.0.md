# v0.13.0 — 2026-11-13

## Overview

You can now change a finished stage's details, such as which acceptance criteria it covers, without editing its files by hand. Two viewer fixes make the file picker and the agent reply notification open where you expect.

Versions beginning with zero remain experimental: any release, including a patch, may contain breaking changes.

## Breaking changes

None.

## Improvements

- **Update a finished stage's details.** `stage set` now accepts `--finalized --id <stage-id>` to change a finished stage's title, summary, rationale, dependencies or covered acceptance criteria. Before, it only worked on the stage still in progress. When the final check found criteria that an earlier stage implemented but did not list, the only fix was editing the stage's JSON file by hand. The command checks the result and leaves the stage unchanged if it is invalid. It replaces the whole list of criteria, so include the ones the stage already covers.

## Bug fixes

- **The file picker starts where you opened it.** **Find occurrences** on a file used to select the file's first occurrence, wherever you clicked it. It now selects the occurrence in the stage and step you opened it from, and scrolls it into view.
- **Agent replies open in the Active list.** Clicking the **Agent replied** notification, or **Show** on the banner, could open the **Resolved** list when a resolved thread had an unread reply. It now opens the **Active** list at the thread the agent just answered.

## Updating

Run `/semantic-flow update`, or download `semantic-flow-0.13.0.zip` and its `.sha256` checksum, verify them, and install the complete extracted `semantic-flow` folder.

Node.js 20 or newer and Git remain required for the CLI and viewer. Windows, macOS, and Linux are supported. The implementation and feedback formats remain experimental `0.1` and did not change.

## Known issues

- **Very long tooltips can't be scrolled with the keyboard.** If a stage explanation is taller than the window, keyboard-only users see only the part that fits. Screen readers still read all of it. Tracked in [#143](https://github.com/MortenChristiansenOrg/semantic-code-review/issues/143).

# v0.9.0 — 2026-10-12

## Overview

Interactive review lets the agent handle your feedback while you keep reviewing. Run `/semantic-flow review -i`, and every note you send from the viewer is picked up, answered, and applied without running another command. Questions from the agent now appear in the viewer, where you are already working.

Versions beginning with zero remain experimental: any release, including a patch, may contain breaking changes.

## Breaking changes

- **Questions move from the chat to the viewer.** While handling feedback, the agent no longer asks you anything in the chat. It replies on the thread the question is about, or shows a question card at the top of the viewer with suggested answers. Answer there. This also applies to `/semantic-flow feedback`: your answer is picked up by the next feedback run.
- **Feedback written by this version needs this version.** Agent replies now record which of your comments they answer. Versions before 0.9.0 reject saved feedback containing these replies, even after the thread is resolved. Keep using 0.9.0 or newer for a review once the agent has replied in it.
- **One feedback run at a time per thread.** Each feedback run reserves the threads it picks up. A second run started meanwhile (for example in another terminal) skips them and reports that another run is answering them. A reservation ends when the run replies. Feedback still waiting for an answer becomes available to other runs after 30 minutes without agent activity, or immediately when you start `/semantic-flow review -i` again.

## Improvements

- **Interactive review.** `/semantic-flow review -i` opens the viewer and keeps the agent listening until you press **Stop agent**, mark the review complete, start interactive review again (the new session replaces it), or nothing happens for two hours. Finished rounds and your answers to the agent's questions count as activity. Anything you send while the agent works waits for its next round, including follow-ups on threads it is still answering. Stop takes effect once the current round is finished. Interactive review works for local implementations; reviews of remote branches (`--branch`) still support personal notes only.
- **See what the agent is doing.**
  - The viewer shows whether an agent is listening, working (with its progress), or not running. When none is running, it offers the command to start one.
  - Each feedback thread is marked as queued, being worked on, or answered.
  - When a round finishes, a notice takes you to the new replies, unread replies are highlighted, and the tab title shows how many there are. You can also get a desktop notification while the tab is in the background.
- **Faster answers.** Agents answer question-only threads first, using parallel helpers where their tool supports them, and can change independent stages in parallel.
- **One send, one round.** Notes and replies you send together are handled together.
- **No feedback left behind.** A regular `/semantic-flow feedback` run also handles feedback you send while it is working before it finishes.
- **The viewer shows its own version.** The header shows the release of the viewer that is actually running. After an update, reopening the review replaces an older running viewer; an update started inside the project's repository restarts it automatically.
- **Updates from anywhere.** `/semantic-flow update` now works when started outside a Git repository.

## Bug fixes

- A follow-up you sent while the agent was working on that thread could be treated as answered by the agent's reply. It now stays queued for the next round.
- The viewer could briefly show a partly restacked implementation. Restacks now appear all at once.
- Paging forward through a long file now starts at the top of the new page, and paging back starts at its bottom. A late response no longer resets a diff you have since switched away from.

## Updating

Run `/semantic-flow update`, or download `semantic-flow-0.9.0.zip` and its `.sha256` checksum, verify them, and install the complete extracted `semantic-flow` folder.

Node.js 20 or newer and Git remain required for the CLI and viewer. Windows, macOS, and Linux are supported. The implementation and feedback formats remain experimental `0.1`; no data migration is required.

To start interactive review, ask for `/semantic-flow review -i`. In tools that can run a command in the background and resume afterwards, such as Claude Code, the conversation stays free while the agent listens. Other tools keep the agent busy with repeated waits.

## Known issues

- If an agent stops unexpectedly in the middle of a round, its unanswered threads become available again only after 30 minutes. Starting `/semantic-flow review -i` again releases them immediately.

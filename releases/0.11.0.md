# v0.11.0 — 2026-10-30

## Overview

The evidence details are simpler: they now close with an X button, and the button for adding a note is gone.

Versions beginning with zero remain experimental: any release, including a patch, may contain breaking changes.

## Breaking changes

- **You can no longer start a note on evidence.** The **Add note** button in the evidence details has been removed. Existing threads on evidence still appear beside its pill, where you can read them, reply and add further notes. To comment on evidence without a thread, add a note to its change node instead.

## Improvements

- **Simpler evidence details.** An X button replaces the **Close** text button.

## Updating

Run `/semantic-flow update`, or download `semantic-flow-0.11.0.zip` and its `.sha256` checksum, verify them, and install the complete extracted `semantic-flow` folder.

Node.js 20 or newer and Git remain required for the CLI and viewer. Windows, macOS, and Linux are supported. The implementation and feedback formats remain experimental `0.1` and did not change.

# v0.7.0 — 2026-09-28

## Overview

Find a changed file anywhere in a review with **T**, then jump straight to the stage and change node you want. This release also improves Markdown previews and makes the location of new isolated worktrees predictable.

Versions beginning with zero remain experimental: any release may contain breaking changes.

## Breaking changes

None.

## Improvements

- Press **T** or choose **Find file** to search by filename, path fragment, or abbreviation. Results include every matching occurrence, grouped by stage and change node, with the change type and stage-level line counts. Renamed files also match their previous paths.
- Use the arrow keys to select a result, **Tab** to complete its filename, **Enter** to open its diff, and **Esc** to close search. The T shortcut stays inactive while typing or using another dialog. Files changed in multiple places have a **Find occurrences** button for jumping between those changes.
- New implementation and simulation worktrees honor explicit destinations and established repository conventions. Otherwise, they use `<main-project-path>.worktrees/<feature-slug>`, even when the session starts in a linked worktree. The skill reports the selected path and avoids overwriting occupied destinations.

## Bug fixes

- The Markdown **Source / Preview** toggle stays in place when switching views.
- Inline code in Markdown previews now has a distinct background and border that remain readable across wrapped lines.

## Updating

Run `/semantic-flow update`, or download `semantic-flow-0.7.0.zip` and its `.sha256` checksum, verify them, and install the complete extracted `semantic-flow` folder. Node.js 20 or newer and Git remain required for the CLI and Viewer; Windows, macOS, and Linux are supported.

The implementation and feedback formats remain experimental `0.1`. This release introduces no format migration and does not move existing worktrees. If upgrading from before v0.5.0, also read the intervening releases' breaking changes before continuing existing reviews.

# v0.8.1 — 2026-09-30

## Overview

Code-linked insights are easier to read and explore in the viewer. This explicitly requested patch release corrects the layout and interactions introduced in v0.8.0.

Versions beginning with zero remain experimental: any release, including a patch, may contain breaking changes.

## Breaking changes

None. No artifact, feedback, or CLI format changes.

## Improvements

- Inline insights show their type icon and highlight the linked code range on hover or keyboard focus.
- Node-level reasoning and **View code** actions share a single pill, separated by a divider. Each action keeps its existing behavior.
- Insight dialogs animate when opening and closing, while respecting reduced-motion preferences.

## Bug fixes

- Inline insight text uses the normal UI font, aligns wrapped lines consistently, and wraps independently of the source-code wrapping setting.
- Insights remain visible at the same horizontal position while long source lines scroll, including when the diff has a visible vertical scrollbar.
- Closing an insight dialog clears the code highlight and restores keyboard focus without leaving the range highlighted.
- Reasoning tooltips preserve line and paragraph breaks.

## Updating

Run `/semantic-flow update`, or download `semantic-flow-0.8.1.zip` and its `.sha256` checksum, verify them, and install the complete extracted `semantic-flow` folder.

Node.js 20 or newer and Git remain required for the CLI and viewer. Windows, macOS, and Linux are supported. The implementation and feedback formats remain experimental `0.1`; no data migration is required.

# v0.7.1 — 2026-09-28

## Overview

File search now finds contiguous text in filenames and shows inline completion, with clearer results. This is an explicitly requested patch correction to v0.7.0 rather than the usual experimental minor-version increment.

Versions beginning with zero remain experimental: any release, including a patch, may contain breaking changes.

## Breaking changes

- File search no longer matches directories, previous filenames, or scattered characters. Search with a contiguous part of the current filename: `alog` matches `catalog.ts`, while `ctlg` does not.
- Tab no longer completes a filename. Press **Enter** to open the suggested result directly; Tab uses normal focus navigation.

## Bug fixes

- Matching is limited to the current filename and remains case-insensitive. **Find occurrences** still targets the exact file across its stages and change nodes, including when other directories contain files with the same name.
- The suggested filename remainder appears as muted text after your query. The first result is selected by default; arrow keys select another result and update the suggestion. Completion stays aligned when long queries scroll and stays out of the way while editing or composing text.
- Search results show the filename on the primary line and the directory in smaller text underneath. Change statuses use the same glyphs, colors, and accessible labels as file headers.

## Updating

Run `/semantic-flow update`, or download `semantic-flow-0.7.1.zip` and its `.sha256` checksum, verify them, and install the complete extracted `semantic-flow` folder. Node.js 20 or newer and Git remain required for the CLI and Viewer; Windows, macOS, and Linux are supported.

The **T** shortcut still opens file search outside text fields. The implementation and feedback formats remain experimental `0.1`; this release requires no data migration. If upgrading from before v0.5.0, also read the intervening releases' breaking changes before continuing existing reviews.
